# 原神跑图小窗 · haruka-genshin-mini-player

一个 Windows 小工具：在《原神》「无边框窗口化」上面放一个**置顶、鼠标穿透、可缩放**的 B 站视频小窗，边跑图边看视频。

它不会注入游戏、不会 hook 游戏进程，就是一个独立的 Electron 窗口；窗口里是正常的 B 站网页，登录、搜索、评论、弹幕都能用。

## 功能

- **正常浏览**：启动是普通 B 站网页，能搜索、能扫码登录、能点视频，不会自动缩窗。
- **一键小窗**：按 `0` 切成默认 `480×270`、屏幕左下角、永远置顶的小窗；再按 `0` 回到浏览窗口。
- **鼠标穿透**：小窗不挡鼠标，点画面会落到游戏里；四个角各 24px 热区可以拖拽缩放。
- **沉浸模式**：小窗里按 `9`，只保留播放控制和 `9`；鼠标移到窗口上时才整窗半透明，移开恢复不透明。
- **无边框窗口**：自绘最小化 / 最大化 / 关闭按钮，拖动顶栏移动，双击最大化 / 还原。
- **登录态持久化**：登录一次长期有效，1080P 需要登录。

## 环境要求

- Windows 10 / 11
- 《原神》显示模式设为 **无边框窗口化**（独占全屏下任何窗口都压不住游戏）
- 从源码运行需要 Node.js 22.12+ 和 pnpm
- 未登录 B 站最高 480P，登录后可看更高画质

## 安装与启动

```bash
pnpm install
pnpm start
```

`pnpm start` 会先编译再启动。也可以安装后直接双击 **`start.cmd`**（首次会自动编译）。

启动后是一个 B 站首页窗口。如果窗口没有出现，检查环境变量 `ELECTRON_RUN_AS_NODE` 是否被设成了 `1`；`start.cmd` 已经会清掉它。

## 使用

1. **让原神切到无边框窗口化**：设置 → 图像 → 显示模式 → 无边框窗口化。
2. **搜视频、点开**：视频会在当前窗口正常播放，评论和推荐都还在。
3. **按 `0` 进小窗**：默认左下角、置顶、鼠标穿透；再按 `0` 回浏览窗口。
4. **拖四角缩放**：鼠标移到小窗任意一个角，出现缩放手柄后拖动即可；松手恢复穿透。
5. **按 `9` 进沉浸模式**：鼠标移到窗口上才半透明，移开恢复；再按 `9` 退出。

## 热键

| 功能 | 键 |
| --- | --- |
| 进入 / 退出视频模式（小窗） | `0` |
| 后退 5 秒 | `5` |
| 前进 5 秒 | `6` |
| 播放 / 暂停 | 反引号 `` ` `` |
| 进入 / 退出沉浸模式 | `9` |

窗口在前台时，这几个键由页面自己处理，输入框聚焦时不会拦截，所以搜索框里可以正常打 `5.0`；窗口失焦（游戏在前台）时才注册为系统级全局热键。

沉浸模式下 `0` 停用，`9`、`5`、`6` 和反引号仍可用。

## 命令行参数

| 参数 | 作用 |
| --- | --- |
| `--resume` | 启动时恢复上次看的视频（默认从 B 站首页开始） |
| `BV1xx411c7mD` / 视频链接 | 直接打开某个视频（仍是正常浏览窗口） |
| `--size=640x360` | 小窗初始尺寸（默认 `480x270`，16:9），本次运行内沿用 |

自检 / 截图等调试参数见 [AGENTS.md](AGENTS.md)。

## 已知限制

- **仅 Windows**：全局热键、置顶层级、鼠标穿透都按 Windows 行为实现。
- **小窗固定在主显示器左下角**：位置不可拖动，但大小可以拖四角调整（最小 `240×135`）。
- **需要无边框窗口化**：独占全屏下窗口无法显示在游戏上方。
- **小窗会占一点 GPU**：跑图掉帧时可以按 `0` 退出小窗。
- **未登录只有 480P**：B 站策略，登录后即可解锁更高画质。
